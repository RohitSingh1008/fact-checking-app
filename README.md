# Fact-Checking Web App

This Streamlit app verifies claims (numbers, years, percentages) found in PDF documents by checking them against live web search results.

## How to Run Locally
1. Install requirements: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`

## Deployment
Deploy directly on [Streamlit Cloud](https://streamlit.io/cloud) by connecting this GitHub repo.
